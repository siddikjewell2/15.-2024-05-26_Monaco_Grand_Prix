# Motorcycle Tax Relief Banner Generator - README

## Project Title
Bangladesh Motorcycle AIT Removal - Good News Banner

## Description
This project creates social media banners announcing the Government of Bangladesh's decision to remove the proposed Advance Income Tax (AIT) on motorcycles. Designed for bikers' communities, especially Royal Enfield True Lover BD.

## Background
In 2026, the government withdrew the AIT proposal on motorcycles after peaceful discussions with bikers. This is NOT a luxury tax - motorcycles are essential for daily commuting, jobs, and livelihood for millions in Bangladesh.
